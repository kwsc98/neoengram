Artifact 是逻辑身份

不绑定单一区域或存储；区域 placement 只作为内部实现存在。

Playground 是生产入口

单 Volume、单 Region、可写；Pre-commit 完成后才能发布 Commit。

Commit 是不可变版本

单 parent，可带 Tags；用户界面只显示 Commit ID 与 Tags。

Snapshot 是区域交付

每个 Snapshot 有独立 ID、单 Volume、单 Region；同一 Commit 可以创建多个区域 Snapshot。

区域间不建立直连

没有 Agent-to-Agent 或 NFS-to-NFS 通道；跨区内容经中心 S3 交付。

四类路径

控制面与数据面分离，任何实现都不能让大文件经过中心 API。

路径 方向 承载内容 边界
产品 API UI / CLI → Center 租户范围内的查询、创建和业务动作 认证、RBAC、幂等、审计
Agent 控制 Agent ↔ Center Assignment、状态、进度、Index 和元数据 Agent 主动连接；中心决定授权与最终状态
对象传输 Agent ↔ Central S3 不可变对象、Manifest 约束下的 payload 仅使用短期 ticket；S3 是耐久权威
业务 I/O Pod ↔ StorageVolume Playground 的 RW 或 Snapshot 的 RO 文件访问 不经过 Agent 或中心 API；不得跨 Region 直连
